# Performance Lab 发布与打包要求

## 部署目标

Performance Lab 作为 Aurora Racing 官网的独立子站，部署在：

```text
https://lab.aurora-racing.com/
```

项目保持独立运行，不依赖主站的 CSS、JavaScript 或运行时。发布包应适用于普通静态网站托管，便于通过宝塔面板上传和更新。

## 一、网站部署包

请提供一个可直接部署的 ZIP。解压后，文件结构如下：

```text
index.html
css/
  ...
js/
  ...
```

要求：

- `index.html` 直接位于 ZIP 根目录，不要再套一层项目文件夹。
- 页面、样式和脚本之间使用正确的相对路径，并保留所需的加载顺序。
- 不要将 `node_modules`、`.git`、开发环境、测试截图或本地启动工具放入部署包。
- 不要包含密钥、账号信息或其他敏感配置。
- 页面继续使用哈希路由，确保部署到静态服务器后不需要额外配置路由重写。
- 包内保留运行页面所必需的 HTML、CSS、JavaScript 和数据文件。

## 二、图片通过七牛 CDN 加载

图片不放入网站部署 ZIP。页面图片统一使用以下地址格式：

```text
https://cdn.aurora-racing.com/performance-lab/版本号/assets/图片路径
```

例如：

```text
https://cdn.aurora-racing.com/performance-lab/v5.0.0/assets/aurora-logo.png
```

目前 `v5.0.0` 的图片已上传至七牛云：

- 如果本次更新没有修改图片，可以继续使用现有地址。
- 如果新增或修改图片，请使用新的版本目录，例如 `v5.1.0`，避免覆盖旧图片和 CDN 缓存冲突。
- 新版本图片目录应包含该版本页面所引用的全部图片，包括沿用的图片，以便完整上传到新的版本前缀。
- 请另外提供完整图片素材 ZIP，保留 `assets/` 内的目录结构，方便我们上传七牛。部署包中的路径必须与素材包路径完全对应。

## 三、集中配置 CDN 地址

建议将图片根地址集中配置，正式打包时可以指定，例如：

```text
https://cdn.aurora-racing.com/performance-lab/v5.1.0/assets/
```

HTML、CSS、JavaScript 动态生成的商品图片、车型图片、Logo、图标等都应使用该地址，避免部分图片仍然引用本地 `assets/`。

本地开发可以继续使用本地图片；正式打包时切换到 CDN 地址。

## 四、每次发布提供的文件

1. **网站部署包 ZIP**：只包含 `index.html`、`css/`、`js/` 等运行必需文件。
2. **完整图片素材包 ZIP**：新增或修改图片时提供，保留完整目录结构。
3. **更新说明**：注明版本号、主要改动、图片是否更新、CDN 版本路径，以及是否需要额外服务器配置。
4. **源码或源码仓库对应版本标签**：方便后续维护；源码和部署包分开提供。

## 五、发布前检查

- 通过 HTTP 服务打开部署包，检查首页、商店、评测、文化和服务页面。
- 检查手机和电脑端显示、页面跳转与主要交互。
- 确认浏览器控制台没有关键错误，CSS、JavaScript 和图片没有 404。
- 确认图片请求指向指定 CDN 地址。如果新图片尚未上传七牛，请在更新说明中注明，由我们上传后再进行最终验证。
- 确认现有购物清单、表单草稿等功能仍能正常使用。

## 六、后续功能扩展

当前项目用于展示和需求整理，没有自动支付、库存或订单后端。如果后续新增这些功能，请在更新说明中单独列出需要部署的后端、数据库、环境变量、外部服务和新增依赖，并说明升级及数据迁移步骤。
