# 第二阶段：工作台入口与登录页

日期：2026-10-16。状态：本地实现、构建和打包完成；用户于 2026-10-17 确认已在宝塔上线。线上只读复核与收尾情况见[第二阶段收尾记录](PHASE_2_CLOSEOUT.md)。

## 本轮范围

- 官网手机端汉堡菜单移除工作台入口，保留桌面导航最右侧入口；沿用现有 768px 分界。移动端通过分享链接直接进入登录页仍然可用。
- 登录页改为白色与浅灰紫整体底板，大圆角外框、胶囊输入框与按钮。两侧共用连续背景，不采用独立深色图片区。
- 整体外框加入橙、蓝、玫红、紫四色色散边缘及柔光，5 秒渐变流动、3 秒柔光呼吸；独立外层承载光晕，白色内容底板仍裁剪圆角。手机缩小光晕范围，减少动态效果偏好下停止边框动画。用原生 CSS 实现，不增加依赖。
- 登录页左上角复用官网移动端 `logo-mobile.webp`，保留原始紫绿配色与图片比例，通过现有 `getAssetUrl()` 加载。
- 左侧仅保留放大的芯片线路 SVG 动画，删除品牌胶囊标签、宣传标题、说明、功能标签、线路文字和暂停按钮；收紧 SVG 留白并移除高度上限。页面底部文字及右侧标题下方的介绍文案也已移除。用现有 React/CSS 实现，没有引入 styled-components。
- 右侧重做登录表单，下方链接到 [fyl66/i3pro](https://github.com/fyl66/i3pro)，说明“也可本地运行，查看源码与安装指南”。该地址已核对为 i3pro 上游仓库。
- 右侧表单采用阿里巴巴普惠体 3：标题 600、标签和按钮 500、输入内容和辅助文字 400。仅调整该区域字体，左侧芯片与官网字体保留。三个官方原始 WOFF2 合计约 15.46 MiB，未裁剪或转换；`font-display: swap` 让文字先显示系统字体，再切换为普惠体。
- 保留账号验证、密码可见性切换、大写锁定提示、错误与繁忙反馈、自动填充语义以及分享链接回跳。
- 密码框通过 `::-ms-reveal` 隐藏 Edge 原生显示密码按钮，避免输入后与页面自带眼睛按钮重复；保留自动填充及自定义显示/隐藏切换。
- 账号和密码框改为悬停时浅紫柔光呼吸（2.8 秒循环），移除鼠标点击后持续的焦点高亮；鼠标离开后柔光淡出。Tab 导航保留独立焦点提示，禁用输入框不触发悬停效果，触屏不启用悬停呼吸，减少动态效果偏好下使用静态柔光。
- 按用户提供的原版恢复细长霓虹灯条、深色线路与黑色端点：线宽 1.8、虚线 40/400、偏移 438→0、3 秒周期及 `cubic-bezier(.5, 0, .9, 1)`。取消额外亮点、错峰延迟、路径长度归一化与芯片呼吸效果，保持原始运动节奏。桌面和手机均自动循环播放；系统“减少动态效果”偏好下去掉发光，保留用户要求的流动速度。

## 交付与发布边界

本地预览启动方式：

```bash
npm run dev -- --port 3011 --strictPort
```

打开 `http://localhost:3011/telemetry-login.html` 查看登录页，`http://localhost:3011/` 查看官网。生产登录路由仍为 `/login`。

- 官网构建：`dist/`；本轮正式官网包：`build/phase2-release-20261017/aurora-website.zip`。
- 登录静态目录可由 `npm run package:telemetry` 重新生成；本轮正式登录包：`build/phase2-release-20261017/telemetry-login.zip`。

实际发布由用户在宝塔手动完成：登录包中的 `telemetry-login.html` 和 `assets/` 上传到 `/srv/i3pro-login/`，官网包上传到原网站根目录。详细顺序见[上线交接](PHASE_2_RELEASE.md)。这不是服务器代码包，不应上传到 `/opt/aurora-telemetry-auth/`。回退时恢复旧 HTML 及其引用的资源。

本轮新增普惠体字体随登录包分发，无需单独上传到字体 CDN。首次加载完整字库较大，后续可由浏览器缓存带哈希资源。本机没有自动上传、重启服务、提交或推送 Git；线上匿名检查结果与未独立验证的交互见收尾记录。
